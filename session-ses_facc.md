## Assistant (Build · Big Pickle · 25.4s)

O erro `permission denied for schema public` é uma permissão no banco do Supabase — o papel `anon` (usado pela anon key) sem acesso à tabela `profiles`.

Não é um problema do seu código React. É permissão SQL no Supabase.

Para resolver, no painel **Supabase → SQL Editor**, rode:

```sql
-- Dá acesso ao schema public para os papéis utilizados
GRANT USAGE ON SCHEMA public TO anon, authenticated, service_role;

-- Garante permissões padrão para futuras tabelas
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON TABLES TO anon, authenticated, service_role;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON SEQUENCES TO anon, authenticated, service_role;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON FUNCTIONS TO anon, authenticated, service_role;

-- Concede permissões na tabela profiles (e em outras que você use)
GRANT ALL ON TABLE profiles TO anon, authenticated, service_role;
```

Substitua `profiles` por todas as tabelas que o app usa (turmas, alunos, pontuacoes, etc.) ou rode o `ALTER DEFAULT PRIVILEGES` que já cobre as novas.

Se o login ainda falhar, verifique também:
- Se há **Row Level Security (RLS)** ativa em `profiles` com políticas que liberem `SELECT` para o próprio usuário — sem uma política, mesmo com `GRANT`, o `anon` não consegue ler.
- Para confirmar o erro do RLS, em **Authentication → Policies** veja se existe uma policy de `SELECT` em `profiles`.
